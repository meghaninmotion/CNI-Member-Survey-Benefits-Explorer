About this resource

This interactive dashboard presents findings from CNI's Fall 2024 Member Survey (180 respondents). It is built as a single self-contained HTML file with no server-side dependencies — all survey data is embedded directly in the page. Three tabbed views let users explore the data: a stacked bar chart showing how members rate overall membership value across five tenure groups; a filterable horizontal bar chart showing how frequently each benefit category was mentioned by tenure; and a set of Venn diagram cards illustrating the three most common combinations of benefits selected by members in each tenure group. Interactivity is powered by Chart.js for the charts and vanilla JavaScript for the tab navigation, tenure filters, and dynamically rendered Venn diagrams.

Visualization developed with assistance from Claude (Anthropic).
